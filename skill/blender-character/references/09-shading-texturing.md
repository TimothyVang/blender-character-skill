## Goal
Every part has a named material that says what it is made of: skin with subsurface scattering and broken-up colour,
layered eyes under a clear cornea, hair that takes light as hair, cloth and leather with a colour map plus fine
surface texture, metal, teeth, gums, tongue. Sculpted cloth detail held in `Multires` is baked to normal maps, so the
meshes going on to rigging carry only a light `Subdivision` modifier. All images are saved in a `textures` folder.
The course works in three passes [14:27:50]: (1) blockout, a flat colour plus rough/metal values per part;
(2) textures: painted colour maps, baked maps, masks; (3) procedural nodes on top to break up whatever looks flat,
since uniform colour and roughness read as dull and a material should hint at wear or newness [14:30:52].

```python
# verified in 4.5.16 background
import bpy, os, numpy as np
W, K, G = (1, 1, 1, 1), (0, 0, 0, 1), lambda v: (v, v, v, 1)
def new_mat(name):                       # empty node tree with one Material Output
    m = bpy.data.materials.get(name) or bpy.data.materials.new(name)
    m.use_nodes = True; nt = m.node_tree; nt.nodes.clear()
    return m, nt, nt.nodes.new("ShaderNodeOutputMaterial")
def N(nt, kind, **props):
    n = nt.nodes.new(kind)
    for k, v in props.items(): setattr(n, k, v)
    return n
def ramp(nt, stops, interp="LINEAR", src=None):      # Color Ramp; stops = [(position, rgba), ...]
    n = nt.nodes.new("ShaderNodeValToRGB"); cr = n.color_ramp; cr.interpolation = interp
    cr.elements.remove(cr.elements[1]); stops = sorted(stops)
    cr.elements[0].position, cr.elements[0].color = stops[0]
    for pos, col in stops[1:]: cr.elements.new(pos).color = col
    if src is not None: nt.links.new(src, n.inputs["Fac"])
    return n
def mix(nt, blend, fac, a, b):           # Mix node, colour mode: inputs 0=Factor 6=A 7=B, colour result .outputs[2]
    n = nt.nodes.new("ShaderNodeMix"); n.data_type, n.blend_type = "RGBA", blend
    for sock, v in ((n.inputs[0], fac), (n.inputs[6], a), (n.inputs[7], b)):
        if isinstance(v, bpy.types.NodeSocket): nt.links.new(v, sock)
        else: sock.default_value = v
    return n
def new_image(name, size=4096, color=(0, 0, 0, 1), data=False, folder=None):
    img = bpy.data.images.new(name, size, size, alpha=True); img.generated_color = color
    if data: img.colorspace_settings.name = "Non-Color"          # masks, pointiness, normals
    if folder: img.filepath_raw = os.path.join(folder, name + ".png"); img.file_format = "PNG"
    return img
```

### 5. Hair, brows, lashes [14:58:38 to 15:04:22]
The concept has dark roots and lighter tips. `Curves Info > Intercept` runs 0 at the root to 1 at the tip, so a
Color Ramp on it multiplied (Factor 1.0) over the hair colour puts that gradient on every strand. The result feeds a
`Principled Hair BSDF` (`Chiang`, `Direct Coloring`, `Roughness` 0.3, `Radial Roughness` 0.3, `IOR` 1.55: defaults)
into a `Material Output` with target Cycles. The hair BSDF previews badly in EEVEE, so a second output with target
EEVEE gets a plain `Principled BSDF` fed the same colour [15:02:26]. Brows and lashes get the same layout.

```python
# verified in 4.5.16 background
def build_hair(name, color, root=K, tip=W):
    m, nt, out = new_mat(name); out.target = "CYCLES"
    grad = ramp(nt, [(0.0, root), (1.0, tip)], src=N(nt, "ShaderNodeHairInfo").outputs["Intercept"])
    rgb = N(nt, "ShaderNodeRGB"); rgb.outputs[0].default_value = color
    col = mix(nt, "MULTIPLY", 1.0, grad.outputs["Color"], rgb.outputs[0]).outputs[2]
    hair = N(nt, "ShaderNodeBsdfHairPrincipled", model="CHIANG", parametrization="COLOR")
    nt.links.new(col, hair.inputs["Color"]); nt.links.new(hair.outputs["BSDF"], out.inputs["Surface"])
    pb = N(nt, "ShaderNodeBsdfPrincipled"); nt.links.new(col, pb.inputs["Base Color"])
    nt.links.new(pb.outputs["BSDF"], N(nt, "ShaderNodeOutputMaterial", target="EEVEE").inputs["Surface"]); return m
```

### 6. Eyes [15:04:22 to 15:18:14]
Two objects per eye. The eyeball has three slots: sclera, iris (procedural), pupil (an `Emission` shader set to
black, so nothing reflects in it). A second, slightly larger sphere is the cornea: clear glass carrying the highlight.
Iris, driven from UVs so it turns with the eye:
1. Unwrap the iris faces alone so the ring is centred in UV space with the top of the iris at the top; shrink the
   other eyeball islands into a corner [15:05:35, 15:10:19]. `Texture Coordinate.UV -> Mapping (Location X -0.5,
   Y -0.5)` then puts the gradient centre on the island centre.
2. `Gradient (Spherical) -> Color Ramp (Ease)`: black, iris colour, lighter iris colour, black. Inner black meets the
   pupil, outer black is the dark rim. On the frame at 15:08:05 the stops sit near 0.50, 0.57, 0.66, 0.71; they
   depend on island size, so set them by looking.
3. `Gradient (Radial) -> Noise Texture.Vector`; `Noise.Fac` soft-lit over the ring at Factor 1.0 makes the radial
   fibres [15:08:17]. The noise scale is raised by eye.
4. `Gradient (Linear) -> Color Ramp (Ease, dark grey #313131 to white)` multiplied over that at Factor 1.0 darkens
   the top half, as if shaded by the lid [15:09:56]. Result `-> Principled BSDF.Base Color` with `Roughness` 1.0 and
   `Specular IOR Level` 0.0: the iris is matte and the cornea supplies the shine.

Cornea [15:13:00]: UV sphere at the eyeball centre, scaled to just enclose it, smooth, material with `Roughness` 0.0
and `Transmission Weight` 1.0; `Shadow` off under Object > Visibility or it darkens the eyeball in Cycles. The
eyeball is parented to it. For EEVEE: `scene.eevee.use_raytracing`, `Raytraced Transmission` in the material, and
a `Value` of 0.0 into `Material Output.Thickness` so the glass does not bend the view [15:15:27]. Then drop the
mirror modifier, suffix `_L`, apply transforms, duplicate mirrored across X as `_R`, recalculate normals.

```python
# verified in 4.5.16 background (builds and renders; stops and noise scale must be tuned by eye per character)
def build_iris(name, iris, light, stops=(0.50, 0.565, 0.66, 0.71), noise_scale=40.0):
    m, nt, out = new_mat(name); mp = N(nt, "ShaderNodeMapping"); mp.inputs["Location"].default_value = (-0.5, -0.5, 0.0)
    nt.links.new(N(nt, "ShaderNodeTexCoord").outputs["UV"], mp.inputs["Vector"])
    def grad(kind):
        g = N(nt, "ShaderNodeTexGradient", gradient_type=kind); nt.links.new(mp.outputs["Vector"], g.inputs["Vector"]); return g
    ring = ramp(nt, list(zip(stops, (K, iris, light, K))), "EASE", grad("SPHERICAL").outputs["Fac"])
    noise = N(nt, "ShaderNodeTexNoise"); noise.inputs["Scale"].default_value = noise_scale
    nt.links.new(grad("RADIAL").outputs["Color"], noise.inputs["Vector"])
    fibres = mix(nt, "SOFT_LIGHT", 1.0, ring.outputs["Color"], noise.outputs["Fac"])
    lid = ramp(nt, [(0.0, G(0.03)), (0.6, W)], "EASE", grad("LINEAR").outputs["Fac"])
    col = mix(nt, "MULTIPLY", 1.0, lid.outputs["Color"], fibres.outputs[2])
    p = N(nt, "ShaderNodeBsdfPrincipled"); p.inputs["Roughness"].default_value = 1.0
    p.inputs["Specular IOR Level"].default_value = 0.0
    nt.links.new(col.outputs[2], p.inputs["Base Color"]); nt.links.new(p.outputs["BSDF"], out.inputs["Surface"]); return m
def build_cornea(name):
    m, nt, out = new_mat(name); p = N(nt, "ShaderNodeBsdfPrincipled")
    p.inputs["Roughness"].default_value = 0.0; p.inputs["Transmission Weight"].default_value = 1.0
    nt.links.new(p.outputs["BSDF"], out.inputs["Surface"]); v = N(nt, "ShaderNodeValue"); v.outputs[0].default_value = 0.0
    nt.links.new(v.outputs[0], out.inputs["Thickness"]); m.use_raytrace_refraction = True; return m
def add_cornea(eye, name, scale=1.02):   # scale is my number; the course fits it by eye
    bpy.ops.mesh.primitive_uv_sphere_add(radius=max(eye.dimensions) / 2 * scale, location=eye.matrix_world.translation)
    c = bpy.context.object; c.name = c.data.name = name; bpy.ops.object.shade_smooth(); c.visible_shadow = False
    eye.parent = c; eye.matrix_parent_inverse = c.matrix_world.inverted(); return c
```

### 7. Colour maps [15:18:27 to 16:22:50]
For skin, shirt, skirt and boots the course makes one 4096 x 4096 image each (`<n>_skin_color_map` and so on),
created filled with the blockout colour, saved at once into a `textures` folder, plugged into `Base Color`, then
painted by hand in Texture Paint for about an hour of time-lapse. From the frames: warmer red on cheeks, nose tip,
lips, ears, knuckles and knees; darker tone in creases and under the chin; lighter tone on raised forms; the printed
motif on the shirt. Habits shown: a saved palette per part; face-selection masking to keep paint on one region
[15:23:51]; a soft paint brush resized for the target; and a Blur brush tried for edges, though the artist says it
works poorly [15:24:50]. A `Hue/Saturation/Value` node (Saturation 1.04, Value 1.1) sits between the skin map and `Base Color` in the time-lapse.
`blender-live` has no paint brush. The workable route: paint a colour attribute on vertices with numpy, then bake
it to the image with `bake_emit` (step 8). It does soft tonal work well and cannot do sharp motifs.

```python
# verified in 4.5.16 background
def paint_points(obj, name, base, dabs):   # dabs = [(centre xyz in object space, radius, rgb, strength 0..1)], linear rgb
    me = obj.data; attr = me.color_attributes.get(name) or me.color_attributes.new(name, "FLOAT_COLOR", "POINT")
    co = np.empty(len(me.vertices) * 3, np.float32); me.vertices.foreach_get("co", co); co = co.reshape(-1, 3)
    col = np.tile(np.array(base, np.float32), (len(co), 1))
    for centre, radius, rgb, strength in dabs:
        t = np.clip(1.0 - np.linalg.norm(co - np.array(centre, np.float32), axis=1) / radius, 0.0, 1.0)
        w = (t * t * (3 - 2 * t) * strength)[:, None]
        col[:, :3] = col[:, :3] * (1 - w) + np.array(rgb, np.float32) * w
    attr.data.foreach_set("color", col.ravel()); me.update(); return attr
def face_mask(obj, name, is_masked):       # face-corner mask: black where is_masked(face centre, object space)
    me = obj.data; attr = me.color_attributes.get(name) or me.color_attributes.new(name, "BYTE_COLOR", "CORNER")
    vals = np.ones((len(me.loops), 4), np.float32)
    for p in me.polygons:
        if is_masked(p.center): vals[p.loop_start:p.loop_start + p.loop_total, :3] = 0.0
    attr.data.foreach_set("color", vals.ravel()); me.update(); return attr
```

Mirror each dab in X. After each round, `render_image` from the front and `compare_images` against the concept.

### 8. Bake pointiness maps [16:23:07 to 16:28:30; skirt 16:39:30, boots 16:47:00, body 17:04:15]
Pointiness is Cycles' measure of how convex or concave the rendered surface is at each point (with `Multires` on it
sees the sculpted folds). Through a Color Ramp it is a grey map, light on ridges and dark in creases; multiplied
over the colour map it gives worn edges and shaded folds. It is baked because the live node is Cycles-only and its
detail would vanish with the `Multires`. Course recipe: `Geometry.Pointiness -> Color Ramp` (black stop near 0.45,
white near 0.5 to 0.55, by eye per object; 0.4 and 0.5 on the body) shown directly on the surface. New 4096 image
`<n>_<part>_pointiness_map`, `Non-Color`. Object selected, that image node active, Render Properties > Bake: type
`Emission`, target `Image Textures`, margin 16 px, `Bake from Multires` off. Save the image. A second object sharing
the material and UV space (straps) is baked into the same image with `Clear Image` off [16:44:45].

```python
# verified in 4.5.16 background
def bake_to_image(obj, image, bake_type, clear=True, margin=16):
    bpy.context.scene.render.engine = "CYCLES"
    for slot in obj.material_slots:        # every slot's material needs the target as its active image node
        nt = slot.material.node_tree
        node = next((n for n in nt.nodes if n.type == "TEX_IMAGE" and n.image == image), None)
        node = node or N(nt, "ShaderNodeTexImage", image=image)
        for n in nt.nodes: n.select = False
        node.select = True; nt.nodes.active = node
    for o in bpy.context.view_layer.objects: o.select_set(False)
    obj.select_set(True); bpy.context.view_layer.objects.active = obj
    bpy.ops.object.bake(type=bake_type, use_clear=clear, margin=margin, margin_type="ADJACENT_FACES",
                        target="IMAGE_TEXTURES", use_selected_to_active=False, normal_space="TANGENT",
                        normal_r="POS_X", normal_g="POS_Y", normal_b="POS_Z")    # pass everything explicitly
    if image.filepath_raw: image.save()
def bake_emit(obj, mat, build_color, image, clear=True):   # build_color(nt) returns the colour socket to bake
    nt = mat.node_tree; out = nt.get_output_node("CYCLES"); before = set(nt.nodes)
    old = out.inputs["Surface"].links[0].from_socket if out.inputs["Surface"].is_linked else None
    em = N(nt, "ShaderNodeEmission"); nt.links.new(build_color(nt), em.inputs["Color"])
    nt.links.new(em.outputs[0], out.inputs["Surface"])
    bake_to_image(obj, image, "EMIT", clear)
    for n in set(nt.nodes) - before - {nt.nodes.active}: nt.nodes.remove(n)
    if old: nt.links.new(old, out.inputs["Surface"])          # the material's own surface link is put back
def pointiness(nt, black=0.45, white=0.52):
    return ramp(nt, [(black, K), (white, W)], src=N(nt, "ShaderNodeNewGeometry").outputs["Pointiness"]).outputs["Color"]
def attribute_color(name):                 # to bake a paint_points attribute into a colour map
    return lambda nt: N(nt, "ShaderNodeVertexColor", layer_name=name).outputs["Color"]
```

### 9. Bake Multires detail to a normal map, then drop the Multires [16:28:30 to 16:32:00, 16:42:08, 16:49:50]
A normal map stores per texel which way the detailed surface faced, so the low-poly mesh shades as if the folds were
still there. The course says this is only needed when the character leaves Blender; inside Blender the `Multires`
may stay [16:24:05]. For this skill, bake: later stages want light meshes. No displacement maps are baked.
Course steps per object: new 4096 image `<n>_<part>_normal_map`, `Non-Color`. On the `Multires` modifier switch off
the viewport toggle and press `Conform Base` under Shape, which pulls the base cage onto the sculpted surface. Bake
type `Normal`, space `Tangent`, swizzle `+X +Y +Z`, margin 16 px, `Bake from Multires` off: Cycles renders the
normals of the render-level surface and stores them relative to the base mesh. Save. Add a `Normal Map` node (image
`Color -> Normal Map.Color`, `Normal -> Principled.Normal`), delete the `Multires`, add `Subdivision` (viewport 1,
render 2 on screen), and push out any spot where cloth now dips into skin [16:31:40]. Objects that then share
material and modifiers are joined [16:52:40]. 4.5 has no `Conform Base`, only `Apply Base`
(`object.multires_base_apply`), used below. In my test the bake was identical with the viewport toggle on or off
and valid without applying the base; applying it is still right: the mesh you keep then sits where the sculpt was.
Stage 06's "no Apply Base on clothes" is about stage 06 (the Multires had to survive until this bake); here, at the
bake, the course conforms the base, and `apply_base=True` is the 4.5 equivalent.

```python
# verified in 4.5.16 background
def bake_normal(obj, image, clear=True):   # plain stand-in material: bump/normal maps already wired cannot leak in
    tmp, nt, out = new_mat("_bake_tmp")
    nt.links.new(N(nt, "ShaderNodeBsdfPrincipled").outputs["BSDF"], out.inputs["Surface"])
    saved = [s.material for s in obj.material_slots]
    for s in obj.material_slots: s.material = tmp
    try: bake_to_image(obj, image, "NORMAL", clear)
    finally:
        for s, mat in zip(obj.material_slots, saved): s.material = mat
        bpy.data.materials.remove(tmp)
def bake_multires_normal(obj, image, apply_base=True, hide_in_viewport=True):
    mr = next(m for m in obj.modifiers if m.type == "MULTIRES")
    mirrors = [(m, m.show_viewport, m.show_render) for m in obj.modifiers if m.type == "MIRROR"]
    for m, _, _ in mirrors: m.show_viewport = m.show_render = False      # a live Mirror wrecks the bake
    mr.show_render, mr.show_viewport = True, not hide_in_viewport
    bpy.context.view_layer.objects.active = obj
    if apply_base: bpy.ops.object.multires_base_apply(modifier=mr.name)
    bake_normal(obj, image)
    for m, v, r in mirrors: m.show_viewport, m.show_render = v, r
def multires_to_subsurf(obj, viewport=1, render=2):
    for m in [m for m in obj.modifiers if m.type == "MULTIRES"]: obj.modifiers.remove(m)
    s = obj.modifiers.new("Subdivision", "SUBSURF"); s.levels, s.render_levels = viewport, render
```

### 10. Cloth and leather [16:32:01 to 16:58:06]
One tree for shirt, skirt and boots; only images and factors change.
- Colour: `colour map -> Mix(Multiply).A`, `pointiness map -> .B`, Factor 0.404 on the shirt at one adjustment;
  then `-> Mix(Overlay).A` with a PBR set's base colour in `.B`, adjusted by eye `-> Base Color`.
  The painted colour stays in charge; the PBR colour only adds surface variation.
- The PBR set comes from Poly Haven: `terienka` is shown for the shirt and `brown_leather` is tested before
  selecting the skirt [16:34:45, 16:39:28]; choose maps appropriate to each surface, trying them on a test sphere
  before copying nodes into the character's material. The leather asset screen shows 4K maps. Roughness and
  metallic maps feed their corresponding inputs when present; displacement is deleted. `Mapping` sets texture scale.
- Normals: the course adds the baked map's colour and the PBR normal map's colour with `Vector Math (Add)`, then
  `Vector Math (Normalize)`, into one `Normal Map` node `-> Principled.Normal` [16:37:22]. That is not a correct
  blend: two flat texels (0.5, 0.5, 1.0) become (0.41, 0.41, 0.82), which the `Normal Map` node reads as a tilted
  normal, so the whole surface shades as if leaning. My recommendation, used below, is `Mix (Overlay, Factor 1.0)`
  of the two colours: a flat texel then leaves the other map unchanged.

```python
# verified in 4.5.16 background (with stand-in PBR images; the Poly Haven add-on itself was not run)
def build_cloth(name, color_img, point_img, normal_img, pbr=None, pbr_scale=3.6, point_fac=0.3, pbr_fac=0.3):
    """pbr = dict(color=Image, rough=Image, normal=Image), or None for colour map and baked normals only."""
    m, nt, out = new_mat(name); p, nmap = N(nt, "ShaderNodeBsdfPrincipled"), N(nt, "ShaderNodeNormalMap")
    img = lambda i: N(nt, "ShaderNodeTexImage", image=i).outputs["Color"]
    base, nrm = mix(nt, "MULTIPLY", point_fac, img(color_img), img(point_img)).outputs[2], img(normal_img)
    if pbr:
        mp = N(nt, "ShaderNodeMapping"); mp.inputs["Scale"].default_value = (pbr_scale, pbr_scale, 1.0)
        nt.links.new(N(nt, "ShaderNodeTexCoord").outputs["UV"], mp.inputs["Vector"])
        tex = {k: N(nt, "ShaderNodeTexImage", image=v) for k, v in pbr.items()}
        for t in tex.values(): nt.links.new(mp.outputs["Vector"], t.inputs["Vector"])
        base = mix(nt, "OVERLAY", pbr_fac, base, tex["color"].outputs["Color"]).outputs[2]
        nt.links.new(tex["rough"].outputs["Color"], p.inputs["Roughness"])
        nrm = mix(nt, "OVERLAY", 1.0, nrm, tex["normal"].outputs["Color"]).outputs[2]
    nt.links.new(nrm, nmap.inputs["Color"]); nt.links.new(nmap.outputs["Normal"], p.inputs["Normal"])
    nt.links.new(base, p.inputs["Base Color"]); nt.links.new(p.outputs["BSDF"], out.inputs["Surface"]); return m
```

### 11. Teeth, gums, tongue [16:58:06 to 17:04:09]
Teeth stay as blocked out. Tongue and gums share one procedural tree, tuned by eye beyond the numbers given:
`Texture Coordinate.UV -> Mapping -> Voronoi Texture` (high scale) `-> Color Ramp` (stops pulled together) makes small
cells. That ramp feeds `Bump.Height` (`Invert` on so cells rise, `Strength` 0.235, `Distance` 0.001) `-> Normal`; the
Factor of a `Mix` whose A is an `RGB` node with the tongue colour and whose B is that colour through

`Noise Texture` (high scale, more Detail, Roughness about 0.6) and passed through another Color Ramp, `Roughness`.

(`ShaderNodeTexVoronoi` output `Distance`, `ShaderNodeBump` property `invert`, `ShaderNodeRGB`).

### 12. Skin [17:04:09 to 17:24:00]
Layers, each previewed alone before the next is added:
1. `skin colour map -> Mix(Multiply).A`, `skin pointiness map -> .B`, Factor 0.265 on one visible adjustment [17:06:34].
2. Tattoos and marks go on their own image created with alpha 0 and are mixed over the base with that image's
   `Alpha` as Factor, so the base map is never damaged [17:06:45]. The course mutes it after the demonstration.
3. Edge tint: `Layer Weight.Facing` (`Blend` 0.13) `-> Color Ramp` (B-Spline: white at 0, black at 0.12, another
   black stop further right) soft-lit over the colour at Factor about 0.6 [17:08:52].
4. Variation 1: `Noise Texture` on mapped UVs `-> Color Ramp` (black near 0.52, white near 0.93) is the
   Factor of a `Mix` between the colour (A) and the colour through `Hue/Saturation/Value` with saturation up and
   value down (B) [17:11:35]. One screen shows Mapping scale 4.4 and Noise scale 425.7 [17:12:31].
   Variation 2: the same with a `Voronoi Texture` (scale 193 on screen) and a reversed ramp
   (light grey at 0, black near 0.3); A is the result of variation 1, B the same HSV copy [17:16:27].
5. Lips must not mottle. A colour attribute `color variation mask` (face corner, byte colour), white everywhere and
   black on the lips and inside the mouth, is the Factor of a `Mix` (A black, B the ramp) placed between each
   variation ramp and the Factor it drives [17:16:39]. An image texture can serve as the mask instead.
6. Roughness: the noise through a default Color Ramp, then the same mask `Mix` with A black, so lips come out fully
   glossy; raise A toward white to calm them [17:20:26]. Bump: a copy of that ramp, masked the same way,
   `-> Bump.Height`, `Strength` 0.228, `Distance` 0.001 [17:21:58].
7. Subsurface: `Random Walk (Skin)`, `Weight` 0.5, `Radius` 1.0 / 0.2 / 0.1, `Scale` 0.01 m, `IOR` 1.4, `Anisotropy`
   0. Lowering `Scale` is the course's fix for skin that glows white in Cycles [17:23:27].

```python
# verified in 4.5.16 background. Values marked "mine" are not stated or readable in the course.
def build_skin(name, color_img, point_img, mask_attr="color variation mask", tattoo_img=None, point_fac=0.5,
               noise_scale=300.0, lip_rough=0.0):                       # point_fac, noise_scale: mine
    m, nt, out = new_mat(name); uv = N(nt, "ShaderNodeTexCoord").outputs["UV"]
    img = lambda i: N(nt, "ShaderNodeTexImage", image=i)
    base = mix(nt, "MULTIPLY", point_fac, img(color_img).outputs["Color"], img(point_img).outputs["Color"]).outputs[2]
    if tattoo_img:
        t = img(tattoo_img); base = mix(nt, "MIX", t.outputs["Alpha"], base, t.outputs["Color"]).outputs[2]
    lw = N(nt, "ShaderNodeLayerWeight"); lw.inputs["Blend"].default_value = 0.13
    rim = ramp(nt, [(0.0, W), (0.12, K), (0.4, K)], "B_SPLINE", lw.outputs["Facing"])
    base = mix(nt, "SOFT_LIGHT", 0.6, base, rim.outputs["Color"]).outputs[2]
    alt = N(nt, "ShaderNodeHueSaturation"); nt.links.new(base, alt.inputs["Color"])
    alt.inputs["Saturation"].default_value, alt.inputs["Value"].default_value = 1.2, 0.85      # mine
    mask = N(nt, "ShaderNodeVertexColor", layer_name=mask_attr).outputs["Color"]
    noise, vor = N(nt, "ShaderNodeTexNoise"), N(nt, "ShaderNodeTexVoronoi")
    noise.inputs["Scale"].default_value, vor.inputs["Scale"].default_value = noise_scale, 190.0
    for t in (noise, vor): nt.links.new(uv, t.inputs["Vector"])
    masked = lambda a, r: mix(nt, "MIX", mask, a, r.outputs["Color"]).outputs[2]
    v1 = mix(nt, "MIX", masked(K, ramp(nt, [(0.52, K), (0.93, W)], src=noise.outputs["Fac"])), base, alt.outputs["Color"])
    f2 = masked(K, ramp(nt, [(0.0, G(0.6)), (0.3, K)], src=vor.outputs["Distance"]))
    v2 = mix(nt, "MIX", f2, v1.outputs[2], alt.outputs["Color"])
    rr = ramp(nt, [(0.0, K), (1.0, W)], src=noise.outputs["Fac"])
    bump = N(nt, "ShaderNodeBump"); bump.inputs["Strength"].default_value, bump.inputs["Distance"].default_value = 0.228, 0.001
    nt.links.new(masked(K, rr), bump.inputs["Height"])
    p = N(nt, "ShaderNodeBsdfPrincipled", subsurface_method="RANDOM_WALK_SKIN")
    for k, v in (("Subsurface Weight", 0.5), ("Subsurface Radius", (1.0, 0.2, 0.1)), ("Subsurface Scale", 0.01),
                 ("Subsurface IOR", 1.4), ("Subsurface Anisotropy", 0.0)): p.inputs[k].default_value = v
    nt.links.new(v2.outputs[2], p.inputs["Base Color"]); nt.links.new(masked(G(lip_rough), rr), p.inputs["Roughness"])
    nt.links.new(bump.outputs["Normal"], p.inputs["Normal"]); nt.links.new(p.outputs["BSDF"], out.inputs["Surface"]); return m
```

## Mistakes the course warns about
- Baking with the object not selected or the target image node not active: an error, or a bake into the wrong image.
- Data maps left as sRGB: pointiness, normal and mask images must be `Non-Color` [16:26:40].
- Normal bake with a `Mirror` modifier still on (render toggle above all): a garbage map [16:50:45].
- `Clear Image` off on a first normal bake leaves black patches from earlier tries [16:51:30]; on for a second
  object's bake into a shared image wipes the first object's part.
- Dragging a library material onto the mesh replaces the material you built; copy its nodes in instead [16:34:50].
- Judging pointiness or the hair shader in EEVEE (Cycles only) [16:24:50]; images not saved to disk are lost on reload.
- Default `Subsurface Scale` on a small character turns the skin white [17:23:27].

## What changes for a different character
General: the three passes, the naming, pointiness times colour, baking `Multires` to a tangent normal map, a mask
for where variation applies, two outputs for hair, eyeball plus separate cornea, and fitting subsurface scale to
the character's real size (0.01 suits this roughly human-sized stylized girl; judge yours by render). Specific to
this one: palette, pink iris, exact ramp stops, the Multiply 0.404 / eye-tuned Overlay factors, fabric choices. The list below is my advice.
- Fur or feathers: `build_hair` still applies; for markings feed the colour from a map sampled on the scalp UVs.
- Scales or rough creature skin: keep the skin layering, drive bump from Voronoi, raise `Roughness`, lower subsurface.
- Hard-surface parts (armour, weapons, buckles): no subsurface, `Metallic` 1 for bare metal; use pointiness to
  lighten worn edges (Screen, not Multiply) and to roughen cavities.
- A character leaving Blender needs every procedural layer baked to images too (`bake_emit` for colour and
  roughness), because node work does not export.

## Exit check
1. Counts from `exec_python`: every renderable mesh and curves object has a material in every slot; no object has
   a `MULTIRES` modifier; every used image has a `filepath_raw` and `is_dirty` false; every pointiness, normal and
   mask image has `colorspace_settings.name == "Non-Color"`; each normal map has red/green deviation above 0.
2. `turnaround_sheet` of the whole character in material shading, looked at from every side: no part grey or
   checkered, no seams in colour maps, no black patches from failed bakes.
3. `outline_match(object="CHARACTER", threshold=0.98)` again on the whole character, because `Apply Base` in
   step 9 moves garment meshes. Under 0.98 is failed; a view with no reference picture is "looked at, not measured", never passed.
4. Cycles `render_image` from the front against the concept through `compare_images`; state per part (skin, hair,
   each garment, eyes) whether the colour agrees. "Looks close" is not a result.
5. `mesh_report` on each baked garment: the face count is back to the retopology count.

Failed: any count in item 1 off, a measured outline view under 0.98, or a nameable colour difference from the concept.
